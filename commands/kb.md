---
description: KB 검색 후 답변 (~/.claude/kb/ 조회, 없으면 일반 답변)
---

질문: $ARGUMENTS

## 절차

1. **`okf-knowledge-base` 스킬을 먼저 로드**하고, 검색·읽기는 스킬의 절차를 그대로 따른다.
   (index.md → frontmatter → 본문 lazy loading, 신선도 경고, ollama 위임 흐름 포함)
2. `~/.claude/kb/common/` 과 `~/.claude/kb/local/` 을 조회.
   - `index.md` 먼저 확인
   - 질문 키워드로 grep (파일명·frontmatter·본문)
3. 매치가 있으면:
   - 관련 파일 읽고 근거 기반 답변
   - `timestamp`/`verified-at` 가 `freshness-window`(기본 30일) 초과면 스킬 규칙대로 신선도 경고를 함께 표시
   - 답변 끝에 참조 파일 경로 명시 (예: `근거: ~/.claude/kb/local/aws/vpc.md`)
4. 매치가 없으면:
   - `KB 없음` 명시 후 일반 LLM 지식으로 답변
5. **KB 세션 추적 (첫 `/kb` 에서 시작, 이후 유지)**:
   - 이후 대화에서 사용자가 지적하는 **KB 오류** 또는 **새로 등장한 KB 후보 지식** 을 누적한다.
   - 누적분이 생기면 해당 턴 답변 끝에 한 줄로 표시해 컨텍스트에 남긴다:
     ```
     KB-세션: fix <파일경로> — <수정 요지> / new <제안 경로> — <신규 요지>
     ```
   - 저장·수정은 지금 하지 않는다. `/kb-end` 가 오면 그때 처리한다.
6. 추적 범위: `/kb` ~ `/kb-end` 사이라도 **직전 `/kb` 답변에 대한 후속 대화** (지적·정정·보충 질문) 는 접두어 없이도 추적한다. KB 주제와 무관한 턴 (일반 코딩 작업, 딴 주제 질문 등) 은 추적하지 않는다.

## 규칙

- 시크릿/자격증명은 답변·추적 메모에 담지 않는다.
- KB 근거와 일반 지식을 섞어 답할 때는 어떤 부분이 KB 근거인지 명시한다.
- `/kb-end` 없이 새 대화·세션이 끝나면 추적 내용은 폐기한다 (파일에 쓰지 않는다).
