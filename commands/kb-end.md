## 절차

1. 현재 컨텍스트에서 `/kb` 세션 동안 누적된 `KB-세션:` 표시 항목 (fix / new) 을 모은다.
2. 항목이 없으면: `KB 업데이트 후보 없음. 종료.` 출력 후 끝.
3. 항목이 있으면:
   - `okf-knowledge-base` 스킬을 로드한다.
   - 스킬에게 다음을 전달한다:
     - **수정 대상**: 각 `fix:` 항목 → 기존 파일 경로 + 수정 요지 + 근거 (대화 인용)
     - **신규 저장**: 각 `new:` 항목 → 제안 경로 + 신규 지식 요지 + 근거
4. 스킬의 안전 게이트를 그대로 따른다:
   - AI가 diff 요약 + 출처 제시
   - 사용자 승인 후 실행
   - `~/.claude/kb/common/` 은 절대 직접 수정 금지 (읽기 전용)
   - 신규 저장은 `~/.claude/kb/local/` 만
   - 수정 시 `log.md` 한 줄 기록
5. 처리 완료 후 세션 추적은 종료한다 (다음 `/kb` 는 새 세션).

## 규칙

- 사용자가 명시적으로 승인하지 않은 항목은 저장하지 않는다.
- 시크릿/자격증명은 저장 대상에서 제외한다.
- 승인 거부된 항목은 조용히 폐기한다 (재확인 반복 금지).
